ft-asr track — part 1: build the ASR adapter

Improve --sent-4 by replacing the witness generator. The labeler's four beam hypotheses currently come from the untuned base omni model; here a LoRA is fine-tuned to do ASR and nothing else, and that adapter produces the hypotheses the key-piece loss labels are derived from. Everything downstream (SFT prompt, judge, metric) is held fixed, so a change in EAR is attributable to label quality.

Part 1 · ASR data + adapter (steps 0–5) Part 2 · witness swap, gate, sent4-v2 (steps 6–12)

Decisions on record

ASR training data — fresh mixes, uniform SNR.
Not a reuse of sent4-v1 rows: those SNRs are clumped into the kind bands, and their sentences are the ones the labels get built from. A new set over SLURP devel is both better-conditioned and leakage-free (see §leakage).
Beam diversity — keep 4 beams, but measure the collapse.
Fine-tuned ASR models often return four identical beams, which silently turns “lost only if every witness missed it” into a one-witness rule. Step 8 in part 2 is a hard gate on that number.
Scope — labeler only.
sft_qwen.py and babble_eval_qwen.py keep running the unmodified base model. One variable moves.
Config — one track YAML, every stage reads it.
configs/ft-asr.yaml. Additive: the HR=/TREE=/SENT4= env-var paths in sft.sh, eval.sh, babble_data.sh are not touched, so no existing track's argv changes.

Where the adapter plugs in

The only structural change is the box in red. Read the two columns against each other — every other stage is byte-identical to the sent4-v1 run.

Step 0 — preflight: is devel really disjoint?

The whole leakage argument rests on one claim: babble_data.py only ever reads SLURP train and test (babble_data.py: build_triplets("test", …), build_triplets("train", …), collect_babble_pool), so an adapter trained on devel has heard neither the sentences its witnesses will be judged on nor the ones the sent-4 labels are derived from. SLURP partitions by prompt, so this should hold on sentences too. Verify before spending a GPU hour on it.

Why not just reuse the sent4-v1 train rows, which already carry noisy audio + a clean sentence?

Two reasons, one methodological and one about conditioning.

Leakage. Those rows are drawn from SLURP train, which is exactly the pool build_triplets("train", …) draws the sent4-v2 rows from. The ASR adapter would have memorized the sentences whose key pieces it is then asked to witness. Its transcripts on train rows would look better than they are, pieces would read as recovered, and the label distribution would shift toward answer for a reason that has nothing to do with hearing.

Conditioning. The sent4 SNRs are clumped into the three kind bands (SLOT_SNR_DISJOINT: 12–20 / 5–12 / 0–5 dB) and 25% of the answer rows are clean. An ASR model trained on that mixture sees a trimodal noise distribution; a uniform 0–20 dB sweep is the right training distribution for a model whose job is to be honest at every SNR.

Step 1 — the track config

configs/ft-asr.yaml new

One flat file, unique keys, the whole track. Every value a stage needs is written here explicitly rather than inherited from a script default — that is the point: sent4-v1's reproduction broke because its prompt lived in a Python default that later moved. A value written in this file stays right no matter what the default becomes.

Every key has exactly one field and exactly one CLI flag that overrides it — no renaming, no merging, no prefix rules in the loader. def load_config(path, cls):
    """Build a stage's config dataclass from a flat track YAML.

    Three layers, each overriding the one before: the dataclass holds the
    defaults, the file overrides them, and the CLI overrides the file (see any
    stage's __main__). The dataclass is the only place a default is written --
    argparse holds none, so there is nothing to keep in sync.

    Field names are the YAML key names. Keys a stage does not declare are not
    its business: one flat file serves the whole track, so every stage reads
    the handful it declares and ignores the rest. A script that needs two sets
    of the same value declares both and picks between them itself -- that
    choice belongs to the script, not here.
    """
    import yaml  # only the config path needs it; keep it off the import cost
                 # of every training job that doesn't pass --config

    with open(path) as f:
        raw = yaml.safe_load(f) or {}
    names = {f.name for f in dataclasses.fields(cls)}
    return cls(**{k: v for k, v in raw.items() if k in names})

if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--config")
    # EVERY flag defaults to None. That is not cosmetic: it is the only way
    # argparse can tell "absent" from "passed a value that happens to equal the
    # default", and the override loop below keys on exactly that distinction.
    ap.add_argument("--ds-id", default=None)
    ap.add_argument("--n-rows", type=int, default=None)
    # a bare store_true would default to False, which reads as "passed" and
    # would silently overwrite the file on every run
    ap.add_argument("--no-push", action="store_true", default=None)
    args = ap.parse_args()

    cfg = load_config(args.config, Config) if args.config else Config()
    for key, value in vars(args).items():
        if value is not None and key != "config":
            setattr(cfg, key, value)

    main(cfg)
One helper, three layers. load_config is the only config function in util.py: it reads the file, and the loop above applies the CLI on top. Defaults live in one typed block per stage instead of thirty default= kwargs scattered down a parser, and main(cfg) stays callable from a notebook or another script with a hand-built Config. The cost is the discipline above — every flag must say default=None, including the booleans, or the override loop treats an absent flag as a passed one.
The one sharp edge: booleans only turn on. With action="store_true", default=None, a flag can override False in the file but nothing can override True from the CLI. Where that matters, use action=argparse.BooleanOptionalAction, default=None (Python 3.9+), which gives you both --push and --no-push off one declaration and still reports None when neither is passed.
A misspelled key is inert — read the resolved config. That is the price of one flat file serving six invocations: each stage legitimately ignores 15–20 keys that belong to the others, so there is no per-stage list of “unknown” keys worth printing — a typo would be buried in it. What catches it instead is log(f"config: {cfg}") right after the override loop: a typo'd key leaves its field sitting at the dataclass default, visible in one line at the top of every log. Read it on the first run of each stage.
Moving an existing script's defaults is the risky part. For sft_qwen.py and babble_data.py, every current default= has to be transcribed into the dataclass exactly — miss one and an existing track's behaviour changes even though nothing about its command line did, which is the one thing this plan promised not to do. Do the move by diffing, not by memory, and log the resolved config on startup so the first run of each existing track shows its own settings:

Step 3 — asr_data.py new

Uniform-SNR babble mixes over devel. No GPU pass, no LLM call, no probing loop — the transcript is the ground truth, so there is nothing to label. It writes the target column as the normalized sentence, which is what makes step 4 a six-line change instead of a new Dataset class: SlurpDataset already reads row["target"].

"""Build the ASR-only training set for the ft-asr track.

Fresh babble mixes at a UNIFORM SNR over SLURP's `devel` split -- the one real
speech split babble_data.py never reads. An adapter trained here has heard
neither the sentences its witnesses will be scored on (SLURP test, where the
babble test rows come from) nor the ones the sent-4 labels are derived from
(SLURP train), so the transcripts it produces during labeling are honest at
both ends. See steps/ft-asr.html step 0 for the check that backs that claim.

No GPU and no LLM calls: the transcript IS the ground truth, so there is
nothing to probe and nothing to label. Runs on a CPU node in minutes.

  python asr_data.py --config configs/ft-asr.yaml
  python asr_data.py --config configs/ft-asr.yaml --n-rows 200 --no-push
"""

import argparse
import hashlib
import itertools
import json
import os
import random
import shutil
from dataclasses import asdict, dataclass

import numpy as np
import soundfile as sf
from datasets import Audio, Dataset, DatasetDict
from tqdm import tqdm
from transformers.models.whisper.english_normalizer import BasicTextNormalizer

from babble_data import (
    AUDIO_ROOT,
    AUDIO_SAMPLING_RATE,
    BABBLE_SPEAKERS,
    MAX_AUDIO_SECONDS,
    MIN_AUDIO_SECONDS,
    SEED,
    collect_babble_pool,
    log,
    slurp_ds_stream,
)
from util import load_config

# The probe decodes with .lower().strip() and ASR_PROMPT asks for no
# punctuation, so the target is normalized the same way the witness text will
# be: training on cased, punctuated SLURP text would teach the adapter to emit
# a string the labeler never sees.
NORMALIZER = BasicTextNormalizer()
ROW_ID = itertools.count(1)
MIN_WORDS = 2


@dataclass
class Config:
    """This stage's surface. The field names are the track YAML's key names."""

    slurp_split: str = "devel"
    # the ASR training set: built here, trained on by sft_qwen.py --task asr,
    # which declares this same key as the dataset of its asr run
    asr_ds_id: str = "keylazy/slurp-asr-bab-devel-v1"
    n_rows: int = 8000  # TRAIN rows; the held-out rows come on top
    snr_db: tuple = (0.0, 20.0)
    clean_prob: float = 0.15
    draws_per_utt: int = 1
    test_every: int = 20  # hash(slurp_id) % test_every == 0 -> held out
    no_push: bool = False


def build_rows(cfg, audio_dir):
    """Stream the split once, writing one wav per (utterance, draw)."""
    pool = collect_babble_pool(cfg.slurp_split)

    def mix(clean, rng, exclude_sid):
        """clean + 3-speaker babble at a uniform SNR -> (samples, snr or None).

        Same SNR math as babble_data.probe_by_kinds, minus the per-kind bands:
        this set is meant to condition the model across the whole range, not to
        land a given utterance in a given kind's band.
        """
        if rng.random() < cfg.clean_prob:
            return clean, None

        length = len(clean)
        babble = np.zeros(length, dtype=np.float32)
        clips = [a for sid, a in pool if sid != exclude_sid]
        for b in rng.sample(clips, BABBLE_SPEAKERS):
            if len(b) < length:
                b = np.pad(b, (0, length - len(b)), "wrap")
            else:
                start = rng.randint(0, len(b) - length)
                b = b[start : start + length]
            babble += b
        babble /= BABBLE_SPEAKERS

        snr = round(rng.uniform(*cfg.snr_db), 1)
        # SNR = 10*log10(clean_power / babble_power)
        #   -> target_babble_power = clean_power / 10^(SNR/10)
        target_power = float(np.mean(clean**2)) / (10 ** (snr / 10))
        babble *= np.sqrt(target_power / float(np.mean(babble**2)))
        noisy = clean + babble
        peak = float(np.max(np.abs(noisy)))
        if peak > 1.0:
            noisy = noisy / peak  # rescaling does not change the SNR
        return noisy.astype(np.float32), snr

    train, test = [], []
    skipped = 0
    pbar = tqdm(total=cfg.n_rows, unit="row", dynamic_ncols=True)
    for row in slurp_ds_stream(cfg.slurp_split):
        if len(train) >= cfg.n_rows:
            break

        sentence = NORMALIZER(row["sentence"]).strip()
        clean = row["audio"]["array"].astype(np.float32)
        clean = clean[: MAX_AUDIO_SECONDS * AUDIO_SAMPLING_RATE]
        if len(sentence.split()) < MIN_WORDS or len(clean) < MIN_AUDIO_SECONDS * AUDIO_SAMPLING_RATE:
            skipped += 1
            continue

        sid = row["slurp_id"]
        # Held out by a hash of the id, not by a tail slice: slurp streams every
        # recording of one prompt back to back (up to ~10), so any positional
        # boundary puts the same sentence on both sides of the split.
        held = int(hashlib.md5(str(sid).encode()).hexdigest(), 16) % cfg.test_every == 0
        rng = random.Random(f"{SEED}:asr:{sid}:{len(train) + len(test)}")

        for _ in range(cfg.draws_per_utt):
            rid = next(ROW_ID)
            samples, snr = mix(clean, rng, sid)
            path = os.path.join(audio_dir, f"{rid:06d}.wav")
            sf.write(path, samples, AUDIO_SAMPLING_RATE)
            rec = {
                "id": rid,
                # sft_qwen.py's SlurpDataset reads "target" and "kind"; writing
                # the transcript there means --task asr only has to swap the
                # prompt, not the dataset class
                "target": sentence,
                "kind": "asr",
                "audio": path,
                "snr_db": snr,
                "sentence": sentence,
                "slurp_id": sid,
                "source": "asr-babble",
            }
            (test if held else train).append(rec)
            if not held:
                pbar.update(1)
    pbar.close()
    log(f"skipped {skipped} (too short / <{MIN_WORDS} words)")
    return train, test


def main(cfg):
    log(f"config: {cfg}")

    audio_dir = os.path.join(AUDIO_ROOT, cfg.asr_ds_id.split("/")[-1])
    shutil.rmtree(audio_dir, ignore_errors=True)
    os.makedirs(audio_dir, exist_ok=True)
    log(f"audio dir: {audio_dir}")

    train_rows, test_rows = build_rows(cfg, audio_dir)

    dump = os.path.join(audio_dir, "rows.json")
    with open(dump, "w") as f:
        # the resolved config rides along with the rows: the SNR range and the
        # split are the only things that distinguish one ASR set from another,
        # and a filename cannot carry them
        json.dump(
            {"config": asdict(cfg), "train": train_rows, "test": test_rows},
            f,
            indent=1,
        )
    log(f"wrote {dump}")

    snrs = [r["snr_db"] for r in train_rows if r["snr_db"] is not None]
    log(
        f"train {len(train_rows)} / test {len(test_rows)} rows; "
        f"clean {sum(1 for r in train_rows if r['snr_db'] is None)}; "
        f"snr mean {np.mean(snrs):.1f} min {min(snrs):.1f} max {max(snrs):.1f}"
    )

    dsd = DatasetDict(
        {
            split: Dataset.from_list(rows).cast_column(
                "audio", Audio(sampling_rate=AUDIO_SAMPLING_RATE)
            )
            for split, rows in (("train", train_rows), ("test", test_rows))
        }
    )
    if cfg.no_push:
        log(f"--no-push: built {cfg.asr_ds_id} locally, see {dump}")
        return
    dsd.push_to_hub(cfg.asr_ds_id)
    log(f"pushed {len(train_rows)} train / {len(test_rows)} test rows to {cfg.asr_ds_id}")


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--config")
    # all None: see steps/ft-asr.html step 1 -- the override loop below can only
    # tell "absent" from "passed" if an absent flag is None
    ap.add_argument("--slurp-split", default=None)
    ap.add_argument("--asr-ds-id", default=None)
    ap.add_argument("--n-rows", type=int, default=None, help="TRAIN rows to build")
    ap.add_argument("--snr-db", type=float, nargs=2, default=None)
    ap.add_argument("--clean-prob", type=float, default=None)
    ap.add_argument("--draws-per-utt", type=int, default=None)
    ap.add_argument("--test-every", type=int, default=None)
    ap.add_argument("--no-push", action="store_true", default=None)

class OmniSFTCollator:
    def __init__(
        self, processor, system_prompt=None, heard_reply=False, plain=False,
        task="repair",
    ) -> None:
        self.processor = processor
        self.system_prompt = system_prompt
        # must match the prompt the dataset's targets were built under, and
        # the one babble_eval_qwen.py evaluates with
        self.task_prompt = task_prompt(heard_reply, plain)
        if task == "asr":
            # the ASR adapter's only consumer is babble_data.py's probe pass,
            # which decodes under this exact pair -- a different framing here
            # is a train/probe mismatch, and the witness gets worse rather
            # than better. ASR_SYSTEM_PROMPT replaces QWEN25_SYSTEM_PROMPT for
            # the same reason: it is what the probe sends.
            self.task_prompt = ASR_PROMPT
            if self.system_prompt is not None:
                self.system_prompt = ASR_SYSTEM_PROMPT

Guarding on is not None keeps the family rule intact: qwen3 gets no system prompt at all, exactly as the probe does (babble_data.py:957, asr_sysp = ASR_SYSTEM_PROMPT if base_family == "qwen2.5" else None).

4c. --config

main() becomes main(cfg) and the args. references inside it become cfg. — a mechanical rename over ~30 lines. The dataclass has to reproduce every current argparse default exactly; that is the whole risk of this edit, so transcribe it from the file rather than from memory (the git show one-liner in step 1).
