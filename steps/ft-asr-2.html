Step 6 — util.load_model: attach a thinker.-prefixed adapter to a thinker-only model edit

This is the trap in the whole plan. sft_qwen.py trains OmniForSFT, which subclasses the full Qwen2_5OmniForConditionalGeneration and forwards to self.thinker (sft_qwen.py:189), specifically so the saved adapter keys carry the thinker. prefix that eval-time loading expects. But babble_data.py loads the probe model with thinker_only=True — a bare Qwen2_5OmniThinkerForConditionalGeneration, whose modules have no such prefix. Hand that model to PeftModel.from_pretrained and nothing matches: no exception, no warning worth noticing, and a probe pass that quietly runs base weights. You would spend a full build and eval before discovering the adapter was never applied.

Strip one level off the config's target_modules and off the state-dict keys, then merge. The training path stays exactly the proven one, and the change is local to the adapter branch that already exists in util.py.

The cost is all in base_generate_batch’s generate call. The full model’s generate is a wrapper that re-routes kwargs to the thinker under thinker_* names and needs return_audio=False (see babble_eval_qwen.py:157) — and the eval that established that spelling only ever runs greedy, B=1. Whether num_beams/num_return_sequences reach the thinker at all on this path, and whether the result comes back with B × n_best rows grouped per input the way base_generate_batch unpacks them, is the open question — and it is the one that can silently gut --sent-4, whose labeler calls a key piece lost only if every hypothesis missed it.

Step 6b — answer the question before choosing. This is five minutes and no build. Two utterances through the full model at n_best=4. Two pass conditions, and the second is the one that is easy to fake: 8 rows out, and those rows grouped 4-per-utterance in input order — which is only observable if the two clips say different things. SLURP streams several recordings of the same prompt back to back under one slurp_id, so a plain .take(2) hands you the same sentence twice and grouped vs. interleaved become indistinguishable; the loop below dedupes on slurp_id and prints each reference so you can check group membership by eye. Kept free of babble_data imports on purpose — importing it wants the vLLM host file up.

SPELLINGS = [
    dict(max_new_tokens=64, num_beams=N_BEST, num_return_sequences=N_BEST),
    dict(thinker_max_new_tokens=64, thinker_num_beams=N_BEST,
         thinker_num_return_sequences=N_BEST),
]
for kw in SPELLINGS:

What you seeRead
rows=8, and each group's four strings are variants of its own printed reference B is live. Take it: a 3-line diff in babble_data.__main__ against an unmodified util.load_model — but prefix every generation kwarg with thinker_, never just the ones that error. See the warning below: passing them bare appears to work and silently is not.
rows=2 — the beam kwargs were swallowed Silently one witness. Take option A. This is the failure the whole gate exists to catch, and here it is free.
rows=8 but a group mixes text from both references The wrapper does not group per input the way decoded[i:i+n_best] assumes. Fixable, but it is now a real diff against the beam unpacking too — take A.
rows=8, all 4 identical in both groups, but each group matches its own reference Grouping is proven, diversity is not — clean test audio can genuinely have one dominant hypothesis, and step 7 measures diversity properly on noisy rows anyway. Not a blocker for B.
both spellings raise Take option A.
Passing the kwargs bare is not safe, even when 6b says both spellings agree. The wrapper seeds its forwarding dict as thinker_kwargs = {"max_new_tokens": thinker_max_new_tokens} — default 1024 — and only then copies your bare kwargs across, guarded by if key not in thinker_kwargs. So a bare num_beams=4 is forwarded (nothing seeded it) while a bare max_new_tokens=64 is silently dropped and the model decodes to 1024 tokens. On the short clean clips 6b uses, both spellings hit <|im_end|> long before either cap, so the outputs match and the bug is invisible. On the 30 s noisy probe audio it is not: 4% of the sent4-v1 rows degenerated into dc dc dc dc … for 1024 tokens and dragged corpus WER from 0.42 to 5.32. The rule on the full-model path is prefix everything: {f"thinker_{k}": v for k, v in gen_kwargs.items()}, plus a bare return_audio=False (that one is a real named parameter of the wrapper). 6b cannot catch this — it is a check on beams and grouping only, and short prompts are exactly where a dropped length cap hides.

Until 6b is run, A is the recommendation: it keeps the generate call byte-identical to the one that produced sent4-v1 and moves the risk into a place that raises SystemExit instead of quietly degrading. But 6b is cheap enough that not running it is the wrong call — a pass makes B strictly the smaller change.

Step 7 — asr_eval_qwen.py: WER and beam diversity new

Two numbers decide whether the rest of the plan is worth running: WER (is it a better witness?) and distinct hypotheses per utterance (is it still four witnesses?). Deliberately standalone — it does not import babble_data, so the gate does not depend on the vLLM judge box being up.

Count distinctness after normalizing, not before. Beam search does return n_best distinct hypotheses, but distinct as token-id sequences, and the tokenizer is not injective onto text: the model can spell one string several ways (it is not held to canonical BPE, so " monday" and " mon"+"day" are two beams and one word), and ten a m / ten am / 10 a m are three sequences that any substring test reads as the same evidence. label_sent_beam reads text — a piece counts as heard if any hypothesis contains it — so the honest witness count is over NORMALIZER(h), and a raw len(set(hyps)) would let a beam that has already collapsed sail through the step 8 threshold. The script reports both, so the gap between them is visible rather than inferred.
"""WER + beam-diversity diagnostic for the ft-asr adapter.

The decision gate of the ft-asr track (steps/ft-asr-2.html step 8). Runs the
probe's exact ASR call -- get_prompts("asr", family), 4 beams,
ASR_MAX_NEW_TOKENS -- over the held-out split of the asr_data.py dataset (the
rows whose slurp_id % test_every == 0), and reports two things per model:

  wer                  top-1 word error rate, overall and per SNR band
  distinct_hyps        mean number of DISTINCT hypotheses among the K returned

The second is the one that can quietly invalidate --sent-4: its labeler marks a
key piece lost only if EVERY hypothesis missed it, so if fine-tuning collapses
the beam to one repeated string, the consensus rule silently becomes a
one-witness rule and the label distribution shifts for a reason that has
nothing to do with hearing better. Distinctness is counted AFTER the Whisper
normalizer, because the beam returns K distinct *token* sequences and the
tokenizer is not injective onto text: the model can spell one string several
ways (non-canonical BPE), and "ten a m" / "ten am" / "10 a m" are three
sequences but one witness as far as the labeler's substring test is concerned.

Standalone on purpose: no babble_data import (which would require the vLLM
host file), no judge, no LLM calls.

  python asr_eval_qwen.py --config configs/ft-asr.yaml --tag base
  python asr_eval_qwen.py --config configs/ft-asr.yaml --tag ft \
      --adapter-path checkpoints/Qwen2.5-Omni-3B-asr-sft
  # the sampling fallback, if the beam collapses:
  python asr_eval_qwen.py --config configs/ft-asr.yaml --tag ft-sampled \
      --adapter-path checkpoints/Qwen2.5-Omni-3B-asr-sft --sample-temp 0.7
"""

import argparse
import json
import os
import tempfile
from dataclasses import dataclass

import numpy as np
import soundfile as sf
import torch
from datasets import Audio, load_dataset
from qwen_omni_utils import process_mm_info
from tqdm import tqdm
from transformers.models.whisper.english_normalizer import BasicTextNormalizer

from prompts import get_prompts
from util import detect_model_family, load_config, load_model

AUDIO_SAMPLING_RATE = 16000
# the probe's cap, so a truncation that hurts the witness hurts it here too
ASR_MAX_NEW_TOKENS = 64
BATCH = 8
NORMALIZER = BasicTextNormalizer()
# the sent-4 kind bands, so a WER row maps onto the kind it will decide
BANDS = (
    ("clean", None, None),
    ("0-5", 0.0, 5.0),
    ("5-12", 5.0, 12.0),
    ("12-20", 12.0, 20.1),
)


@dataclass
class Config:
    """Field names are the track YAML's key names, as everywhere else."""

    omni_path: str = "Qwen/Qwen2.5-Omni-3B"
    asr_ds_id: str = "keylazy/slurp-asr-bab-v1"
    adapter_path: str = None
    split: str = "test"
    num_rows: int = -1
    n_best: int = 4  # the probe's ASR_N_BEST
    sample_temp: float = 0.0  # >0 replaces beam search with K samples
    ref_column: str = "target"
    tag: str = "run"
    out: str = None


def main(cfg):
    print(f"config: {cfg}")
    family = detect_model_family(cfg.omni_path)
    name = (cfg.adapter_path or cfg.omni_path).rstrip("/").split("/")[-1]
    out = cfg.out or f"results/asr_{name}_{cfg.tag}.jsonl"
    os.makedirs("results", exist_ok=True)

    ds = load_dataset(cfg.asr_ds_id, split=cfg.split)
    ds = ds.cast_column("audio", Audio(sampling_rate=AUDIO_SAMPLING_RATE))
    if cfg.num_rows > 0:
        ds = ds.select(range(min(cfg.num_rows, len(ds))))
    print(f"{len(ds)} rows from {cfg.asr_ds_id}:{cfg.split} -> {out}")

    model, processor = load_model(
        cfg.omni_path, family, adapter_path=cfg.adapter_path, thinker_only=True
    )
    sysp, userp = get_prompts("asr", family)
    im_end = processor.tokenizer.convert_tokens_to_ids("<|im_end|>")

    @torch.inference_mode()
    def transcribe(paths):
        """The probe's ASR call, batched. -> one list of n_best strings per path."""
        convs = []
        for path in paths:
            conv = []
            if sysp is not None:
                conv.append(
                    {"role": "system", "content": [{"type": "text", "text": sysp}]}
                )
            conv.append(
                {
                    "role": "user",
                    "content": [
                        {"type": "audio", "audio": path},
                        {"type": "text", "text": userp},
                    ],
                }
            )
            convs.append(conv)
        texts = processor.apply_chat_template(
            convs, add_generation_prompt=True, tokenize=False
        )
        audios, images, videos, *_ = process_mm_info(convs, use_audio_in_video=False)
        inputs = processor(
            text=texts,
            audio=audios,
            images=images,
            videos=videos,
            return_tensors="pt",
            padding=True,
        ).to(model.device, dtype=model.dtype)
        if cfg.sample_temp:
            # the fallback witness scheme: K independent samples instead of K beams
            gen_kwargs = dict(
                do_sample=True,
                temperature=cfg.sample_temp,
                top_p=0.95,
                num_return_sequences=cfg.n_best,
            )
        else:
            gen_kwargs = dict(
                do_sample=False,
                num_beams=cfg.n_best,
                num_return_sequences=cfg.n_best,
            )
        gen_ids = model.generate(
            **inputs,
            max_new_tokens=ASR_MAX_NEW_TOKENS,
            eos_token_id=im_end,
            pad_token_id=im_end,
            **gen_kwargs,
        )
        gen = gen_ids[:, inputs["input_ids"].shape[1] :].cpu()
        dec = [
            t.lower().strip()
            for t in processor.batch_decode(gen, skip_special_tokens=True)
        ]
        return [dec[i : i + cfg.n_best] for i in range(0, len(dec), cfg.n_best)]

    edits = {b[0]: [0, 0] for b in BANDS}
    edits["all"] = [0, 0]
    distinct, distinct_raw, n_rows = [], [], 0
    fout = open(out, "w")
    for start in tqdm(range(0, len(ds), BATCH), unit="batch", dynamic_ncols=True):
        batch = ds.select(range(start, min(start + BATCH, len(ds))))
        paths = []
        for row in batch:
            fd, path = tempfile.mkstemp(suffix=".wav")
            os.close(fd)
            sf.write(
                path, row["audio"]["array"].astype("float32"), AUDIO_SAMPLING_RATE
            )
            paths.append(path)
        try:
            hyp_lists = transcribe(paths)
        finally:
            for path in paths:
                os.remove(path)

        for row, hyps in zip(batch, hyp_lists):
            ref = NORMALIZER(row[cfg.ref_column]).strip()
            if not ref.split():
                continue
            top = NORMALIZER(hyps[0]).strip()

            # (edit distance, len(ref)) over whitespace tokens -- WER's
            # numerator and denominator kept apart so the corpus rate is a
            # ratio of sums, not a mean of per-row rates (jiwer and evaluate
            # are not installed in these envs)
            r, h = ref.split(), top.split()
            d = np.arange(len(h) + 1)
            for i in range(1, len(r) + 1):
                prev = d.copy()
                d[0] = i
                for j in range(1, len(h) + 1):
                    d[j] = min(
                        prev[j] + 1,
                        d[j - 1] + 1,
                        prev[j - 1] + (r[i - 1] != h[j - 1]),
                    )
            e, n = int(d[len(h)]), len(r)

            edits["all"][0] += e
            edits["all"][1] += n
            snr = row["snr_db"]
            for label, lo, hi in BANDS:
                if (snr is None and lo is None) or (
                    snr is not None and lo is not None and lo <= snr < hi
                ):
                    edits[label][0] += e
                    edits[label][1] += n
                    break

            # distinct AFTER normalization: the beam returns K distinct token
            # sequences, but two of them spelling one string ("ten am" vs
            # "ten a m", or the same words under a different BPE split) are
            # one witness to the labeler, which only ever does a substring
            # test on the text. The raw count is kept alongside so a gap
            # between them is visible rather than inferred.
            uniq = len({NORMALIZER(hyp).strip() for hyp in hyps})
            distinct.append(uniq)
            distinct_raw.append(len(set(hyps)))
            n_rows += 1
            fout.write(
                json.dumps(
                    {
                        "id": row["id"],
                        "snr_db": snr,
                        "ref": ref,
                        "hyps": hyps,
                        "edits": e,
                        "n_ref": n,
                        "distinct": uniq,
                        "distinct_raw": distinct_raw[-1],
                    }
                )
                + "\n"
            )

    summary = {
        "type": "summary",
        "model": cfg.omni_path,
        "adapter": cfg.adapter_path,
        "dataset": f"{cfg.asr_ds_id}:{cfg.split}",
        "ref_column": cfg.ref_column,
        "sample_temp": cfg.sample_temp,
        "n_best": cfg.n_best,
        "rows": n_rows,
        "WER": round(edits["all"][0] / max(edits["all"][1], 1), 4),
        "wer_by_band": {
            b: (round(edits[b][0] / edits[b][1], 4) if edits[b][1] else None)
            for b, _, _ in BANDS
        },
        # the gate reads distinct_hyps_mean; distinct_hyps_raw_mean is the
        # same count before normalization, i.e. how much of the beam's
        # apparent diversity is spelling
        "distinct_hyps_mean": round(float(np.mean(distinct)), 3) if distinct else None,
        "distinct_hyps_raw_mean": (
            round(float(np.mean(distinct_raw)), 3) if distinct_raw else None
        ),
        "distinct_hyps_hist": {
            str(k): int(sum(1 for x in distinct if x == k))
            for k in range(1, cfg.n_best + 1)
        },
    }
    fout.write(json.dumps(summary) + "\n")
    fout.close()
    print(json.dumps(summary, indent=1))


if __name__ == "__main__":
    ap = argparse.ArgumentParser()

    main(cfg)

Drag the sliders. # --- util.py ---
def omni_generate(model, inputs, **gen_kwargs):
    """model.generate for either shape of omni model. -> the generated ids only."""
    prompt_len = inputs["input_ids"].shape[1]
    cap = gen_kwargs["max_new_tokens"]
    if hasattr(model, "thinker"):
        gen_kwargs = {f"thinker_{k}": v for k, v in gen_kwargs.items()}
        gen_kwargs["return_audio"] = False  # a real named param, not forwarded
    out = model.generate(**inputs, **gen_kwargs)
    ids = out[0] if isinstance(out, tuple) else out

            "Qwen2_5OmniForConditionalGeneration.generate's thinker_kwargs "
            "routing, and steps/ft-asr-2.html step 6b."
        )
    return gen

The config block

No prefix here: this stage reads the flat file's bare keys, and asr_adapter is one of them — it names the LoRA the ASR stage produced, so it belongs to this build rather than to that run.

This is the one script that does not get a main(cfg). babble_data.py's __main__ is already the pipeline body, and it assigns the module globals the worker threads read — TRACK, AUDIO_DIR, PROBE_DIR, base_model, base_processor, base_family, IM_END_ID. At module scope those are plain assignments; inside a function every one of them needs a global declaration, and missing a single name gives you a local that the threads never see — a probe pass running base_model = None. Resolve cfg at the top of __main__ and leave the body where it is; hoisting it is a separate refactor with its own verification, not a side effect of adding a config file.

    echo "vLLM not reachable at ${JUDGE_URL} -- sbatch /gscratch/sciencehub/zanqil/vllm_judge/vllm_judge.slurm" >&2
    exit 1
fi
# the judge box gets re-served with different models, so take the name from the
# server rather than trusting a default -- a mismatch is a 404 on every row
JUDGE_MODEL=$(curl -sf --max-time 10 "${JUDGE_URL}/models" \
    | python -c 'import json,sys; print(json.load(sys.stdin)["data"][0]["id"])')
echo "judge OK at ${JUDGE_URL} serving ${JUDGE_MODEL}"

python -u babble_data.py --config "$CFG"
python -u sft_qwen.py --config "$CFG"

# Two judge passes off the one adapter, as on the sent tracks: the per-kind
# judges (comparable with the beam rows) and the type judge + tree matrix
# (comparable with the tree rows). Numbers are comparable within a judge only.
# Base and adapter both run, so the delta is measured on this dataset rather
# than read across from the v1 table.
for adapter in "" "checkpoints/Qwen2.5-Omni-3B-bab-sent4ft-sft"; do
    name="${adapter:-Qwen/Qwen2.5-Omni-3B}"; name="${name##*/}"
    for pass in "per-kind|sent4-ftasr" "tree|sent4-ftasr-typejudge"; do
        IFS='|' read -r mode tag <<< "$pass"
        flags="--judge-mode per-kind"
        [[ "$mode" == tree ]] && flags="--score-matrix tree"
        echo "=== eval ${name} (${tag}) ==="
        python -u babble_eval_qwen.py --config "$CFG" $flags \
            ${adapter:+--adapter-path "$adapter"} \
            --out "results/bab_results_${name}_${tag}.jsonl" \
            --judge-base-url "$JUDGE_URL" --judge-model "$JUDGE_MODEL"
    done
done
babble_eval_qwen.py --config is the last hookup: the same dataclass + override-loop block, sections ("data", "eval"). Fields base, ds_id, prompt, kinds, num_rows, judge_mode, tag — the names the YAML already uses. Two notes: its existing --plain-prompt flag becomes the same store_const onto prompt that sft_qwen.py uses, and adapter_path stays CLI-only in practice — which model a row evaluates is a driver decision (the loop above runs two), not a property of the track, so no adapter key belongs in the eval: section.

Rollback

Nothing in this plan is destructive. sft.sh, eval.sh and babble_data.sh keep their exact argv, so every existing track reproduces as before; the new YAML only takes effect when --config is passed.
